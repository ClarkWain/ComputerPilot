# Roadmap

ComputerPilot focuses on semantic desktop execution and reusable validated processes.

## Available in v0.6.0

- Native Windows/macOS observation and input, with four public MCP tools.
- Matched Windows Paint/Aseprite profiles within the documented scope.
- Explicit call recording; macOS PNG drawing Replay, export and checked resume.
- Windows x64 and unsigned macOS arm64 Core archives with checksums.

## Next release areas

- Developer ID signing/notarization and a smoother macOS install experience.
- Additional validated macOS hardware/architecture coverage.
- More application profiles backed by actual UI and failure-case validation.
- Broader Replay operations and applications, with explicit handling of uncertain input.
- Integration of validated orchestration capabilities from the historical research branch.
- Reproducible task benchmarks for model round trips, latency and cost.

These are development directions, not shipping guarantees or dated commitments. The [historical orchestration branch](https://github.com/ClarkWain/ComputerPilot/tree/refactor/node-orchestration) remains experimental and retains its original naming. Open [feature requests](https://github.com/ClarkWain/ComputerPilot/issues/new/choose) with a concrete application, task and acceptance condition.
