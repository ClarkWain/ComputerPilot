# Delta 与 Replay 发布前验收（2026-09-24）

范围：`refactor/node-orchestration` 当前工作区。由三个独立审查任务分别核查 Delta、Replay 执行可靠性、Replay 分享与便携包；主验收复核代码、修复确认的问题并重新运行测试。随后在当前远程桌面完成单步与三步真实回放。本报告只反映该工作区状态，不等同于正式发行包已发布。下文保留初轮失败记录，最后一节给出修复后的最新结论。

## 结论

| 能力 | 离线结论 | 发布结论 |
|---|---|---|
| Delta | 核心逻辑和离线收益通过；观察失败后旧基线复用的缺陷已修复并回归 | 可作为内部预览继续验证；真实桌面、DPI、MCP 图片 patch 和实际 Agent token 收益仍待验收 |
| Replay 固定 recipe 核心 | 格式、导出/导入、不确定结果停机及短流程真实播放通过 | 达到短流程预览；长流程和故障恢复证据不足 |
| Replay 易导出、易分享 | 三步包可导出、导入，并在同机新进程及便携包上播放；提供语义操作记录转待审草稿 | 完整目标不通过：无长流程迁移、无异用户/异机真实播放 |

因此，不建议把 Delta + Replay 组合标为正式稳定版。允许在明确标注上述范围的内部预览包中继续验证。

## Delta 有无功能的离线收益

| 配对场景 | 完整模式 | Delta | 说明 |
|---|---:|---:|---|
| 80 个控件、连续无变化，单次 JSON | 8263 B | 61 B | 减少约 99.26%；模拟数据 |
| 固定 400×300 PNG、无变化，JSON / 图片 | 792 B / 3727 B | 61 B / 0 B | 不再向客户端返回图片 |
| 同一 PNG 的 16×16 局部变化，JSON / 图片 | 748 B / 3852 B | 516 B / 586 B | patch 图片减少约 84.8% |

局部 patch 使用返回的 `rect` 与 `frame` 叠加此前完整 PNG，逐像素重建一致。这些是合成数据的响应字节，不代表真实应用的耗时或模型 token；仍需在真实窗口按相同任务配对测量响应、耗时、token 与成功率。客户端若丢失图片基线，必须重新请求完整状态。

## Replay 初轮发现的发布门槛（部分已修复）

1. **流程制作与分享：** CLI 只接受已写好的 recipe，没有把 Agent 操作意图整理成 recipe 的能力。单步保存 PNG 示例不足以代表 5–10 步流程和长流程；长流程案例尚未迁移。
2. **前后置验收：** 当前逐步检查目标唯一、profile、动作回执和可选文件条件；未定义文档身份、画布内容基线与界面稳定等待。仅 `profileAvailable` 的步骤可以执行结束，但现在会明确标记为 `verification:partial`，不能当作作品验收。
3. **恢复与故障：** 超时/部分执行时停止而不盲重试已具备；尚无动作级核验后续播、崩溃恢复入口，以及双进程竞争和锁恢复的专项故障测试。
4. **环境覆盖：** 异用户、异机器、不同 DPI/窗口尺寸、模态框、远程桌面断连、用户插手和连续重复播放尚无真实输入证据。未来 macOS/Linux 执行层也尚未实现。
5. **收益：** 无 Agent 重做与 Replay 的同任务配对数据，尚不能计算制作成本回本次数、接收者配置时间或长流程成功率。

## 后续打磨记录

原验收结论保留为发现时的快照。随后增加了步骤 `before` 条件（窗口标题、profile、可见控件及其值、文件状态）、输出图像像素采样和 `expect` 条件的限时等待；等待期间只观察，不重复派发输入。加入了跨进程输入锁及异常退出后遗留锁恢复测试。Node MCP 现在可通过 `DP_REPLAY_RECORD_DIR` 显式记录语义操作的 intent/receipt，CLI `draft` 从已确认成功且每次只有一个语义动作的记录生成待审核 recipe；遇到基础键鼠批次、部分执行或未知结果会拒绝生成。草稿仍须人工补全目标选择、文档基线及内容级验收，不能直接视为可靠回放。

新增运行日志 `inspect` 与显式 `resume`：通过 recipe 摘要及步骤事件顺序核对已提交前缀；只在下一步具备控件精确值或文件 SHA-256 的前置条件时续播，重新核对现场，不重放已提交动作。未知派发、缺失回执或不完整日志均拒绝续播。该能力通过模拟中断验证，尚待真实应用的文档状态与用户插手案例验收。

离线回归更新为 Node 60/60、C++ 非交互 20/20 通过；真实桌面和长流程发布门槛仍未完成，正式稳定版结论保持“不通过”。
