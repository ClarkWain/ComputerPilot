# Workflow 首版验收

日期：2026-09-25。主验收者负责制定并执行，不以实现代理的自测代替集成验收。

## 验收范围与标准

验证同机文件产物型批次、Aseprite 单帧 PNG 导出、CLI、动态逐项规则、项目边界恢复。所有输入均为一次性测试素材，不操作已有用户文档。实际应用结果与模拟故障结果分别列出。

| 编号 | 用户场景 | 必须满足 |
|---|---|---|
| U01 | 正常处理不少于 20 个素材 | 每项都有状态，PNG尺寸与已知参考像素一致，源摘要不变 |
| U02 | 中文、空格、嵌套同名文件 | 路径与产物映射正确，无覆盖或漏项 |
| U03 | 混合单帧、多帧、损坏、不支持文件 | 正确完成/跳过/失败；汇总总数等于输入清单 |
| U04 | 两个输入映射同一输出 | 派发前拒绝冲突，源与已有输出不变 |
| U05 | 运行前/恢复前输入变化 | 不使用旧计划悄悄执行已变化源 |
| U06 | 项目完成后暂停与续跑 | 已提交项不再派发；未开始项继续；证据有效 |
| U07 | 输入派发后进程中断 | 未知项标待核对，普通resume不能再次派发 |
| U08 | 已完成产物丢失或被修改 | 明确报告证据失效，不继续声称原结果有效 |
| U09 | 两个进程同时执行/续跑 | 唯一writer，另一个拒绝；无重复输入 |
| U10 | pause/cancel 命令 | 边界生效，状态与计数正确，无后续未授权派发 |
| U11 | 动态规则选择跳过/导出 | 决策持久化，完成项恢复不重评估；未信任脚本不加载 |
| U12 | validate/plan/status | 不派发应用、不加载作者JS；JSON和退出码可用 |
| U13 | 超时、异常退出、缺失产物 | 无盲目重试，不留下本次后台子进程 |
| U14 | 输出根/输入根/符号链接异常 | 拒绝路径逃逸、源覆盖与循环扫描 |
| U15 | 日志尾部损坏/顺序异常 | 保守拒绝，不把不完整动作记成功 |
| U16 | 显式核对当前未知项 | 必须满足证据或明确人工选择，保留审计记录 |
| U17 | 换目录重用规则 | 无需修改实现代码即可处理同类新输入 |
| R01 | 现有 Node 功能 | 全量 npm test --prefix node 通过 |
| R02 | Windows worker | windows-release 构建及非交互 ctest 通过 |

通过标准不是所有异常都返回成功：对于未知、冲突和损坏，安全拒绝并给出准确状态就是正确结果。不会用模拟故障通过推断任意真实桌面场景已验证。
